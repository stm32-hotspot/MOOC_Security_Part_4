# MOOC Security Part 4: STM32 security in practice 

Disclaimer: This material was created in 2020 and is delivered as is.

## MOOC purpose 

Understand the basic steps to create secure bootloader with authentication of the firmware.

## Prerequisites
- PC with preinstalled the following software:
    - STM32CubeProgrammer
    - STM32CubeIDE
    - STM32G0 Cube library
    - X-CUBE-CRYPTOLIB
    - OpenSSL tools (awk.exe / grep.exe / hexdump.exe / openssl.exe / sed.exe / srec_cat.exe / wc.exe / xxd.exe)
    -   TeraTerm terminal
- STM32board
    - NUCLEO-G071RB
- microUSB cable
